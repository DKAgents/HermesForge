# US-124 — Brief-builder: real inventory.yaml, context-budgets, cost-30d

- **Train:** 0
- **Priority:** P0
- **Owner profile:** no-agent
- **Model floor:** no-agent
- **Status:** story-ready
- **Campaign:** 2026-09-aegis-rebuild

## Story

As the Aegis Rebuild process, I need a mechanically generated, complete Campaign
Brief pack so that the next campaign runs at full fidelity instead of DEGRADED,
and so that Train-1 (efficiency) and Train-4 (swarm diet) decisions rest on
measured toolsets and cost rather than guesses.

## Background

Evidence from campaign `2026-09-aegis-rebuild`: the brief was incomplete, forcing
a DEGRADED scorecard. Stub/partial files:

- `inventory.yaml` — 3 lines; no `profiles`, `crons`, `data_roots`,
  `discord_channels`, or `publisher_owned_files` arrays.
- `context-budgets.md` — "TODO"; no `/context` dumps.
- `cost-30d.md` — "TODO"; no $/token by job.
- `data-manifest.md` — partial: `last_signal_id: unknown`,
  `fear_greed_last_ok: unknown`, `crosspost_state_bytes` absent.

Because inventory is absent, this campaign issued **no profile/cron DELETE
verdicts** and sequenced **no Train-1 efficiency cuts**. This story unblocks
both.

## Acceptance

- [ ] `inventory.yaml` populated per `templates/campaign-brief.md`: for each of
      the 12 profiles — name, model_floor, enabled toolsets (must not be `all`),
      always_load_skills, writable_paths; for each of the 21 crons — name,
      schedule, agent|no-agent, model, deliver, writes.
- [ ] `context-budgets.md` contains real `/context` dumps for at least:
      orchestrator, researcher, trade monitor, weaver, strategy pipeline.
- [ ] `cost-30d.md` contains tokens + estimated $ by job for the last 30 days.
      No API keys, no credentials.
- [ ] `data-manifest.md` completed: `last_signal_id`, `fear_greed_last_ok`,
      `crosspost_state_bytes`, and snapshot/offbox/restore-drill fields filled.
- [ ] Discord channels recorded by name/ID only — never webhook URLs.
- [ ] Generated by a no-agent script (mechanical) checked into the repo.
- [ ] Test specified: script is idempotent and its output validates against the
      brief template's required keys.
- [ ] Rollback specified.

## Forbidden

- No live-soul edits
- No publisher-file edits unless owner is publisher (this is a no-agent script;
  it only READS config to produce the brief)
- No truncate/replace of history files
- No credentials, webhook URLs, or `.env` values in the generated files

## Rollback

The brief-builder only writes under `campaigns/<id>/`. Delete the generated
files to roll back; nothing in production depends on them.
