# Objectify Role-Reversal Entries With Earnings Binary Filter

## Discovery Summary

E005 acknowledges that 'significant penetration' for role-reversal is inherently subjective (Murphy, p. 83), while C065 and R029 both rely on that same subjective judgment to trigger entries at former support-turned-resistance levels. The seed question introduces an earnings calendar check as a mandatory binary filter — this directly addresses E005's subjectivity problem by adding a hard, objective disqualifier: if earnings are within 7 days, the role-reversal setup is voided regardless of how convincing the penetration appears. This transforms a fully subjective entry decision into one with at least one non-negotiable objective gate.

## Trading Implication

Before acting on any support-turned-resistance or speedline role-reversal setup (C065, R029), a trader must first check the earnings calendar — if an earnings event falls within 7 days, the trade is skipped entirely, removing one layer of subjectivity and avoiding event-driven whipsaws that can invalidate the role-reversal premise.
