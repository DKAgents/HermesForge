# CRB/Bond ratio + relative strength for sector rotation

## Discovery Summary

The CRB/Bond ratio rule (R249) provides a macro regime signal: rising ratio favors inflation-sensitive sectors (gold, oil, cyclicals), falling ratio favors defensive sectors (utilities, financials, consumer staples). Relative strength analysis (N112, C340) then identifies which specific sectors or stocks within that regime are outperforming. Combining them creates a sequential two-step process: first determine the regime, then apply relative strength for precise allocation.

## Trading Implication

Traders should first monitor the CRB/Bond ratio trend to set the sector bias, then use relative strength rankings within the favored group to select the strongest individual sectors or stocks for entry.
