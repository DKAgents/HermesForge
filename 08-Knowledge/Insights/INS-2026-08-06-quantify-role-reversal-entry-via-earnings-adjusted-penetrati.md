# Quantify Role-Reversal Entry Via Earnings-Adjusted Penetration Filter

## Discovery Summary

E005 identifies the core weakness in role-reversal trading: 'significant penetration' is subjective (Murphy, p. 83). C065 and R029 both rely on this same subjective threshold to confirm that support has become resistance (or vice versa) before entering a trade. The seed question introduces a binary earnings calendar filter as a way to impose objective structure around an otherwise subjective entry criterion — if earnings are within 7 days, the role-reversal setup is suppressed regardless of how convincing the penetration appears, because earnings volatility can manufacture false penetrations that mimic 'significant' breaks.

## Trading Implication

Before acting on any role-reversal signal (whether from classical S/R levels per C065 or speedlines per R029), a trader must check the earnings calendar: if an earnings release falls within 7 days, the trade is skipped, effectively using the binary calendar check as a surrogate objective filter to compensate for the subjectivity flagged in E005.
