# Quantify Role-Reversal Threshold Using Earnings as Binary Filter

## Discovery Summary

E005 identifies that 'significant penetration' for role-reversal is inherently subjective (Murphy, p. 83), while C065 and R029 both confirm that violated support/resistance and broken speedlines reverse roles in trending markets. The seed question introduces an earnings calendar check as a mandatory binary filter. Combining these: since the subjectivity of 'significant' penetration is already a known weakness (E005), an imminent earnings event (within 7 days) can cause exaggerated, news-driven moves that falsely appear to be 'significant' penetrations, invalidating the role-reversal signal from C065 and R029 before it can be confirmed.

## Trading Implication

A trader should add an earnings calendar check as a pre-trade binary filter: if earnings are within 7 days of a potential role-reversal entry (whether at a violated support/resistance level per C065 or a broken speedline per R029), the trade should be skipped entirely to avoid acting on a potentially false or earnings-distorted penetration.
