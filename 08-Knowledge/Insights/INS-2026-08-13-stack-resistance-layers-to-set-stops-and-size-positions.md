# Stack Resistance Layers to Set Stops and Size Positions

## Discovery Summary

C065 establishes that violated support flips to resistance in downtrends; EN069 adds that unfilled gaps in a bear move also act as resistance ceilings where short entries can be timed. RG035 completes the chain: once resistance is identified — whether from a flipped support level (C065, Murphy p.83) or a gap (EN069) — that resistance level dictates stop placement (above resistance for shorts), which then determines maximum position size given the 5% portfolio risk cap on a 10% commitment rule (RG035). The non-obvious insight is that when a flipped-support resistance level and a gap resistance level coincide, the cluster provides a tighter, higher-confidence stop placement, allowing a larger position size within the same money management constraint.

## Trading Implication

In a downtrend, when a rally approaches both a prior violated support level (now resistance) and the lower end of an unfilled gap at the same price zone, enter short at that confluence, place the stop just above the gap's upper end, then size the position using RG035's 5%-of-portfolio risk formula — the tighter stop permits a proportionally larger position.
