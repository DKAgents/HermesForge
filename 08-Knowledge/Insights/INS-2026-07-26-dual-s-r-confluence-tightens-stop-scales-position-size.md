# Dual S/R Confluence Tightens Stop, Scales Position Size

## Discovery Summary

C065 establishes that a violated support level becomes a precise, behaviourally-anchored resistance ceiling on bear-market bounces (Murphy p. 83). EN069 adds a second, independent S/R marker at the same juncture: any unfilled gap left during the prior sell-off will also cap that same rally, providing a measurable upper boundary (lower end of the gap) for stop placement. RG035 then closes the loop — once the technical stop level is defined by that dual confluence (role-reversed resistance + gap ceiling), the exact dollar distance to the stop determines maximum allowable position size under the 5%-of-capital risk rule. The non-obvious link is that using *two* converging S/R sources (C065 + EN069) produces a tighter, more defensible stop than either alone, which under RG035's math directly permits a *larger* position size for the same risk budget.

## Trading Implication

In a downtrend, when a bounce rallies into a zone where a prior violated support AND an overhead gap ceiling coincide, place the short entry at the lower boundary of the gap/resistance zone and set the stop just above the gap top; then size the position using RG035's 5%-risk rule against that compressed stop distance to maximise units traded within allowed risk.
