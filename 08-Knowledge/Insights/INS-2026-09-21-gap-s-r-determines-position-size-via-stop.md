# Gap S/R Determines Position Size via Stop

## Discovery Summary

C065 and EN069 establish specific levels for stop placement: violated support becomes resistance in downtrends, and gaps function as support/resistance for timing entries. RG035 then provides the money management rule that stop distance from entry directly determines position size (closer stop = larger position, looser stop = smaller position). Together, these create a sequence: identify an actionable support/resistance level from gaps or role reversal, set the stop just beyond it, then calculate position size using the stop distance and the maximum risk rule from RG035.

## Trading Implication

For a short trade, identify a gap or a former support turned resistance (C065), place the stop above that level (EN069), then size the position so that the stop distance multiplied by position size equals the maximum allowed risk (e.g., 5% of account).
