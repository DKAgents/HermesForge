# Using Gaps to Set Stops in Role-Reversal Zones

## Discovery Summary

The concept of previous-support-turned-resistance (C065) identifies key reversal zones in downtrends where stops should be placed above resistance per RG035. EN069 specifies that price gaps within these zones offer precise technical levels for stop placement — selling a rally into a gap and placing the stop above it. This combines role-reversal theory with gap-based stop precision to satisfy both technical and money management criteria from RG035.

## Trading Implication

When shorting a bounce into a prior support level that has become resistance, use an overhead price gap within that zone to define the exact stop location above the gap, allowing tighter stops and larger position sizing per the 10%/5% rule.
