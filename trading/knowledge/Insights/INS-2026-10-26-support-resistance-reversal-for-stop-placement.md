# Support/resistance reversal for stop placement

## Discovery Summary

Murphy's rule (p.83) shows that violated support becomes resistance in downtrends, and vice versa (C065, C064). This directly supports the seed principle that these identifiable levels can be used to set stop-loss distances, which then determine position size—a core risk management rule.

## Trading Implication

When shorting into a downtrend, place stops just above the old support (now resistance); when buying into an uptrend, place stops just below the old peak (now support). Use the resulting stop distance to size positions via fixed fractional or volatility-adjusted methods.
