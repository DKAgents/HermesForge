# Support/Resistance Flip Dictates Stop Distance

## Discovery Summary

C065 shows that in a downtrend, a broken support level becomes resistance, meaning a short position's stop-loss can logically be placed just above that former support (now resistance). This directly ties to Murphy's rule that support/resistance determines stop distance, which determines position size. The confluence is non-obvious because traders often set stops arbitrarily rather than using the precise level where a failed bounce confirms the role reversal.

## Trading Implication

When shorting into a downtrend that has just broken prior support, set the stop-loss 1-2 ticks above that previously broken support level and use that distance to calculate position size per unit of risk.
