# S/R Levels Set Stops and Position Size

## Discovery Summary

C065 (previous support as resistance) and EN069 (gaps as S/R) both identify concrete price levels for stop placement. The distance from entry to these levels defines per-share risk, which according to the seed principle directly determines position size for a fixed account risk. This connects Murphy's S/R concepts to position sizing.

## Trading Implication

When entering at a gap or prior support level, place the protective stop just beyond that level and size the position so that stop distance times shares equals your predefined risk amount.
