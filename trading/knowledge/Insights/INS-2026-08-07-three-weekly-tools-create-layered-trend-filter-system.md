# Three Weekly Tools Create Layered Trend Filter System

## Discovery Summary

R142 establishes that MACD and Stochastics daily signals must be filtered by weekly direction first. N044 provides two specific weekly trend tools (10/40-week MAs) to define that weekly trend objectively. C130 adds a third option — the weekly price channel breakout — as a potentially superior trend-definition mechanism. Together, these three notes form a tiered system: define weekly trend via 40-week MA or weekly price channel, then only take daily MACD/Stochastics crossovers aligned with that trend.

## Trading Implication

A trader should first confirm weekly trend using either the 10/40-week MA relationship or a weekly price channel breakout, then only enter daily MACD or Stochastics crossover signals that align with the confirmed weekly direction — filtering out all counter-trend daily signals entirely.
