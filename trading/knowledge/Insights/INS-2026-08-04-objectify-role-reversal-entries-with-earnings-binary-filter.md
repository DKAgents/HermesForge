# Objectify Role-Reversal Entries With Earnings Binary Filter

## Discovery Summary

E005 identifies that 'significant penetration' — the trigger for role-reversal trades — is inherently subjective (Murphy, p. 83), which creates inconsistent entry execution. C065 and R029 both describe role-reversal setups (violated support becoming resistance in downtrends, and broken speedlines reversing roles) that depend on this same ambiguous threshold. The seed question introduces a mandatory binary pre-trade filter — an earnings calendar check within 7 days — which, when combined with a quantified penetration threshold, addresses E005's subjectivity by adding an objective external condition that must be satisfied before any role-reversal entry is taken.

## Trading Implication

Before entering any role-reversal trade based on C065 or R029 setups, a trader must (1) define a quantified penetration threshold to address E005 subjectivity and (2) confirm no earnings event falls within 7 days — if earnings are imminent, the trade is skipped regardless of how clean the role-reversal setup appears.
