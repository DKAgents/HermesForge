# Quantify Role-Reversal Significance Using Earnings as Binary Filter

## Discovery Summary

E005 identifies that 'significant penetration' for role-reversal is inherently subjective (Murphy, p. 83), creating ambiguity in both C065 (support-becomes-resistance in downtrends) and R029 (speedline role reversals). The seed question introduces a binary earnings calendar filter to address a parallel ambiguity problem: even if a role-reversal signal appears valid, an imminent earnings event (within 7 days) can produce gap moves that invalidate the level entirely, making the subjective significance threshold moot. By combining the earnings binary filter with role-reversal entries, traders replace one dimension of subjectivity with a hard, objective rule.

## Trading Implication

Before entering any trade based on a support-turned-resistance or speedline role-reversal signal (C065, R029), check whether earnings are within 7 days — if yes, skip the trade regardless of how 'significant' the penetration appears, since earnings gaps can invalidate the price level used to define the role-reversal.
