# S/R role reversal reinforces position sizing rule

## Discovery Summary

Murphy's principle that previous support becomes resistance in a downtrend (C065) can be used to set a tighter stop-loss just above the former support level now acting as resistance. This directly determines stop distance, which then dictates position size for a given account risk, implementing a core risk rule from Murphy.

## Trading Implication

When entering a short position after a support breakdown, set stop-loss just above the former support level; then compute position size so that the stop-loss distance equals the maximum allowed dollar risk per trade.
