# S/R flips set stops and position size

## Discovery Summary

C065 notes that in a downtrend, violated support becomes resistance on bounces (Murphy p.83), while C064 indicates prior peaks become support in uptrends. These flipped levels provide objective invalidation points, so stop distance is measured from entry to the flipped level. That stop distance then determines position size for a fixed risk amount.

## Trading Implication

Before entering, locate the relevant flipped S/R level — above resistance for shorts in downtrends, below support for longs in uptrends — place stops just beyond it, and size positions so the distance equals your planned risk.
