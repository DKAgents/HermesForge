# Layered S/R Levels Enable Precise Stop Placement and Sizing

## Discovery Summary

C065 establishes that violated support becomes resistance in downtrends, while EN069 identifies gaps as additional S/R levels for entry timing. RG035 (Murphy) requires stops to be placed at valid technical levels — above resistance for shorts — and directly ties stop distance to position size. The non-obvious connection is that both role-reversed support (C065) and gap edges (EN069) serve as candidate resistance levels for RG035's stop placement formula, creating a layered, prioritized system: sell into a rally toward role-reversed support OR the lower end of a gap, place stop above whichever level is closer, then calculate position size from that stop distance.

## Trading Implication

In a downtrend, when a rally approaches both a prior violated support level and an unfilled gap, use the lower of the two resistance references to set the tightest technically valid stop above resistance, then back-calculate maximum position size using the 5% risk rule from RG035.
